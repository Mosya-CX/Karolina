# 前端视觉、交互与可替换主题系统

## 目标实现

将本次对话选定的 Karolina 主视觉、B1 K 蝶、粉/青/紫控件、HarmonyOS Sans 字体和定稿看板娘落实到现有工作台。覆盖对话、文档、任务审批、拓展工具、导航、状态、抽屉及全部输入和按钮。现有 API、任务权限、保存冲突检查和草稿保护继续生效。

全套 UI 支持独立替换配色、字体、背景、角色、品牌图、图标、组件样式和效果。提供主题选择、组件预览、主题包导入/导出及恢复默认；无需修改业务功能才能换美术。基础组件与业务页面、主题与动效分离，避免继续增加隐式全局依赖。

## 技术方案

- 保持 .NET 8 / WinForms / WebView2 与原生 ES modules，无新增第三方运行依赖。业务控制器通过显式上下文和动作注册表协作；HTTP、Markdown、UI 原子组件、主题、特效各自负责自身逻辑。
- CSS 拆为基础、布局、按钮框/标签/图标/输入/选择/列表/徽章/弹窗等原子与页面组合；设计变量涵盖颜色、尺寸、字重、切角、偏置节点、指示三角、透明度、间距和运动。同组强文字按钮共享框架。
- 主题包使用版本化 `theme.json`，按资源键覆盖背景、看板娘、品牌、图标，并可逐组件指定 CSS；支持 ZIP 导入与导出。主题偏好和用户包存工程 `.karolina/state/appearance`，不依赖随机端口或 WebView2 缓存。内建主题作为完整基底，部分包覆盖未提供的项目。
- 默认深空夜景保留约 75% 室外视觉权重、约 25% 低亮室内双屏工作台；中景无人机和蓝图角色在室外，远处城市越远越暗。不出现实体大星体、室内手或两侧柱子。
- 品牌采用抽象侧切 K 蝶、透视三角面片、虚化顶点和连线。粉青紫为主，蓝等过渡色只做辅助；按钮采用不对称切角、轻量面片、短促错位/滑入的动感。悬停和选中是框内居中朝下的无尾三角，分别蓝/粉；发送、保存、通过不额外挂粉色箭头。
- WebGL Shader 提供可替换的夜空/稀疏流星效果，页面切换、按钮和节点动效由单独控制器管理。支持系统减少动态效果、手动低动效/关闭、上下文丢失及无 WebGL 回退，后台停止绘制。
- 看板娘使用批准的服装与眼睛设计；手机上的 Agent 仅基础几何表情，不显示名称，随真实工作台状态表达情绪。角色、手机表情及背景均为独立替换项。

## 边界情况

无效主题版本、重复包 ID、路径越界/链接、超限文件、未知资源类型和缺失被引用文件明确报错，导入先验证后发布。加载/Shader 失败提示并回到基础视觉，不能破坏任务或丢失输入。切换主题只更新视觉和偏好，不更改工程内容、会话或审批。高对比文字与键盘焦点可见；窄窗口通过布局适配与导航收起保持功能可达。

## 验收条件

全页面原有操作可达；每个设计资源及组件能用包覆盖；主题重启恢复、导出再导入一致；无效导入保留当前包和偏好；减少动态效果有效、GPU 失败回退；按钮状态与选定方案一致，白袜/瞳孔等角色定稿不另行改设计。真实编译与专项协议/DOM验证分别记录，原生输入验收与视觉人工验收待真实操作；禁止截图验收。

## 附录

批准素材在 `Design/KarolinaCharacter/Final`。此前生成的主视觉、品牌和图标控件样板是本轮制作依据，运行资源必须保存到工程，不能依赖用户个人缓存绝对路径。
