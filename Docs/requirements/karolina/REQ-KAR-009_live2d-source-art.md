# Karolina Live2D 建模素材

## 目标实现

将用户认可的 Karolina 正面原画转换为可继续制作 Live2D 模型的分层素材。由 Agent 准备素材和检查，用户尽量只做软件打开、导入和必要授权。当前批次交付透明部件、拆层清单与可导入 PSD；模型绑定和工作台运行接入分批推进。

## 技术方案

保持用户认可原画的角色身份、左右位置、服装、紫色特殊瞳孔、侧马尾、大蝴蝶结、单层白色中筒袜和手机几何表情。图像工具补绘被遮挡区域；像素切出与 PSD 组装的具体工具方式在实施计划记录，以当前用户授权为准。源素材与运行资源分开，当前仅写 `Design/KarolinaCharacter/Live2D` 和本批次维护工具。

脸部按底层、左右眼白/虹膜/睫毛/眉毛、嘴形拆分；头发按后发、刘海、侧发、马尾与饰品拆分。身体和服装保留完整形态并按实际第一版动作需求拆分。所有部件使用共同画布和明确绘制顺序。PSD 使用 RGB、8 位通道、sRGB、唯一图层名、普通混合模式；不保留未合并图层蒙版。

## 边界情况

AI 补绘可能改变形状、位置或比例，必须对照原图，不能直接把重绘结果作为准确拆层。不得用整图的重复副本冒充独立部件；缺失隐藏区域、透明通道缺陷和边缘接缝如实记录。可解析 PSD 不等于 Cubism 实际导入成功，也不等于绑定和运行验收通过。

保留定稿参考和用户批准的原画文件，不覆盖已有工作。无新增第三方包、Unity 资源修改、工作台 SDK 引入或 Git 提交。本批次源素材不改变 REQ-KAR-008 的运行依赖合同。

## 验收条件

- 导出部件具有真实透明通道和非空有效内容；图层名唯一，画布及位置可追踪。
- 部件组合后保留批准原画外观，眼睛、手机和服装等图层可独立控制。
- 被遮挡区域的补绘和第一版保留的粗分层边界明确。
- 通过真实 Cubism 5.3.04 导入操作确认文档存在；用户需要操作时给出准确入口。
- 不使用截图作为验收证据；绘画预览是素材检查，不宣称软件行为验收。
