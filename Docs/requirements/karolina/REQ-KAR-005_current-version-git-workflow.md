# 当前程序与桌面运行

## 目标实现

Karolina 只保留当前程序输出和统一启动入口。中文正文及界面与编号加英文物理文件名分开；需求演进写正文，元数据保存索引/关联/证据。原生窗口只一套控制，支持输入与托盘生命周期。原 Git 产品条款已被 REQ-KAR-006 的任务变更审批替代。

## 技术方案

- Docs 物理目录和文件名全英文，新建用稳定编号与英文功能名，显示中文标题及模块。
- 计划六阶段与需求激活/废弃分别维护；关闭终态，不因 Agent 完成或任务批准自动关闭。
- 标准 WinForms/NotifyIcon/WebView2 Dock Fill，STA 异步初始化和独占工程 profile，核对实际目录，辅助进程可恢复异常不终止 Agent。
- 原生最小化进入任务栏，X 收起到托盘，双击/菜单恢复，托盘完全退出结束窗口、服务及所属 Codex/WebView2 进程。
- 启动自动连接 Codex/尝试 Unity，空闲重试；不自动运行 Unity 测试、构建或保存场景。用户交互窗口正常显示，辅助进程隐藏。

## 边界情况

单一 current 输出，旧恢复档是取证而非可切换程序版本。退出保留已写工程文件。未保存正文或审批草稿提示，活动 Codex 任务不因收起而停止。维护/扩展采用官方控件，不承诺未经测量的性能倍率。

## 验收条件

真实窗口鼠标与 Windows 键盘验证对话、搜索、文档及任务意见输入；最大化/最小化/托盘恢复后可继续输入。原窗口/托盘证据与新版任务审批的行为证据分开，不能用独立 DOM 赋值替代原生输入。

## 附录

启动入口 Start-Karolina.ps1，唯一输出 artifacts/current。依赖 .NET 8、已授权 Microsoft.Web.WebView2 1.0.4258.31 SDK/Runtime、Codex、Unity MCP；Karolina 产品不依赖 Git CLI/GCM，版本操作用用户外部工具。

## 需求演进

### 2026-10-02 · 接受本轮修订

此前方案把需求演进放进元数据，计划用“草案/待验收”混合机器与人工完成状态，启动时生成多个 GUID 构建目录，Git 页面缺少账号、拉取和提交历史。用户本轮要求改为正文演进、六阶段执行周期、编号加英文文件名和单一当前版本。

选择既有 GCM 浏览器登录及 Git CLI，保持凭据在系统；保留索引选择以限定 Commit 范围。人工验收与自动验证分开，计划不会因构建或 Agent 审查通过自动关闭。过时说明与验收报告归入所属计划后从当前资料目录删除。

影响范围为 Karolina 桌面、项目文档与入口路径；Gameplay 合同、Unity 资源和已有工作区改动保持各自权威。承接 REQ-KAR-004，通过 PLAN-KAR-004 实施。


### 2026-10-02 · 物理目录及 JSON 文件英文命名

用户补充全部物理路径使用英文，包含分类、模块目录和独立元数据/机器事实 JSON。采用 Docs/requirements、plans、rules、engineering、resources，模块采用英文功能名；界面显示仍使用中文 metadata.title/domain。新建提供英文文件标题和英文模块目录，未填模块使用 custom，不把中文标题拼入路径。同步目录、链接、解析器和入口，旧来源路径仅作为历史追溯。

### 2026-10-02 17:59 · 修订 3

变更前：手动连接、手动 Git 刷新、显式暂存分组及网页窗口按钮。

变更后：启动自动连接；Git 自动刷新、单一文件列表和勾选直接 Commit，左侧提交历史；原生最小化、X 收起托盘及托盘退出。

原因：用户实际操作发现流程负担、选择丢失和关闭语义不符。技术采用内部部分提交来保留未选索引，原生容器持有关闭事件。影响：前端不显示暂存步骤，失败保留选择；隐藏窗口不结束 Agent。人工反馈由 PLAN-KAR-004 的校正阶段落实。

### 2026-10-02 19:27 · 修订 4

变更前：WinForms 通过 SetParent 嵌入完整 Edge 窗口；句柄和独立 DOM 检查通过，但人工使用仍看到浏览器控制且无法输入。

变更后：采用 Microsoft.Web.WebView2 1.0.4258.31 官方页面控件，原生窗口只保留一套控制；不再使用跨进程整窗嵌入。

原因与技术选择：实际 Windows UI Automation 点击并发送键盘后旧输入值为空，焦点仍未进入输入框。用户授权自行判断，要求性能、维护和扩展体验更好，选择正式 SDK 与 STA 消息循环承载现有页面；不承诺未经对比测量的性能倍率。使用独占工程 profile，允许系统 Runtime 更新。

边界与兼容：SDK 只进入 Karolina，Unity 的包/资产/Gameplay 合同保持原权威。标题栏 X 仍收起到托盘，完整退出由托盘完成，后台任务不会因可恢复页面异常被强制结束。由 PLAN-KAR-004 校正实施；验收改为真实窗口点击/键盘输入，禁止截图。



### 2026-10-02 · Git 产品能力退役，改为任务变更审批

变更前：内建 Git 工作区、账号、提交和远端操作。变更后：用户明确取消 Git，改为按具体计划任务开始基线审查 Unity 文件，逐文件/整体审批、意见和退回执行。细节见 REQ-KAR-006，由 PLAN-KAR-005 实施；其它对话、文档、连接及原生窗口合同保留。旧 Git 描述仅在需求演进中保留追溯，不是当前产品范围。
