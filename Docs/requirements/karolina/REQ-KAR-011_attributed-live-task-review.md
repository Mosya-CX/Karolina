# 有来源归属的自动任务审批

## 目标实现

审批仅收录确认属于Agent的变更；人工资源排除，来源未知独立确认。永久略过.meta。后台异步同步，保留未变指纹的审批/意见与前端草稿。每个文件先展示Agent具体做了什么、原因和真实验证/限制。资源审批不展示YAML、二进制、哈希/大小统计或原始资源差异入口；代码同样需要说明，并保留代码diff与行意见。

## 技术方案

来源与指纹绑定；成功Codex文件写入回执须核对补丁和写后哈希，命令/MCP执行时间不证明作者。人工可确认来源；未知不能整体批准。文件变化重置旧决定。保留修订核对与批准前真实全量校验，文件监听去抖和增量缓存用于后台同步。

### 来源确认与审批边界

文件使用 agent/human/unknown 三种归属。任务时间窗口和扩展名只说明候选范围，不证明作者；.anim也可能由Agent生成，人工提供的代码也不该自动算Agent。成功Codex文件补丁按原基线或该任务已证明的上一写后版本重建，严格检查内容、换行和写后哈希一致才自动认领；命令/MCP没有逐文件可信回执时保留未知。混合作者无法证明的文件需人工确认。

未知与人工在来源面板显示，Agent文件才进入批准集合；人工可填写依据批量确认或更正来源。确认绑定当前path/fingerprint，弹窗展示后文件再变必须重新核对。原有审批记录缺少归属证据时不追溯伪造Agent身份。

### 实时同步与逐文件操作说明

三个资源根目录使用文件监听标记变化，后台约3秒去抖扫描。用规范路径、修改时间和大小缓存哈希；目录移动/删除失效其子项缓存。冻结视图更新时保留未变文件的决定与意见，变更版本重置决定及归属；批准前完整读取实际文件再次比对，后台缓存不能作为批准证据。

逐文件Explanation独立于Origin、Decision和Notes，含Fingerprint、Summary、WhatChanged、Why、Verification、Source。不能以行数、文件类型、序列化字段列表代替业务操作说明。未知来源显示为“文件变更说明·来源待确认”，人工资源不参与审批。

执行上下文要求Harness在最终回复附karolina-review结构化说明，整体摘要移除该代码块。只有成功写入回执且已证明写后哈希一致的Agent文件自动绑定该回复，不能绑定同期人工改动的新版本。只有结构化代码块、缺少整体文字时记录明确“未提供整体总结”的提示，仍进入待审批。

旧任务可以通过“让Agent补充文件说明”以只读模式分析冻结差异。发送冻结指纹、有限差异证据与限制，完成后再次核对冻结版本；过大内容先检查容量，明确未完整分析，不能推断业务结果。这种分析不证明原修改者，也不改变来源或审批决定。未知/人工代码与动画都不能靠文件扩展名自动认领。

审批页独立选择说明模型和思考档位，不沿用AI对话的模型。首次默认只从服务真实返回的mini/nano/luna系列选择，并优先低档位；没有识别到低档模型或低档位时要求人工选择，禁止静默改用高级默认模型。人工选择按工程保存在本机，后续可修改。生成状态绑定任务与运行编号，显示实际模型/档位、耗时、阶段、收到的输出字符数和最终保存文件数，不伪造百分比或尚未保存的逐文件进度。停止仅针对同一说明轮次，成功、失败、中断和回执未知均需可见；本地保留最近一轮状态，程序重启未收到终态的轮次明确中断。

当前版说明缺失时可保存意见、驳回或退回任务，但不能单独/整体批准Agent文件；前后端均核对说明指纹。文件版本变化使旧说明失效；完全退出仍恢复说明与来源。

摘要保存与文件同步分离，不再要求人工“提交差异”。前端仅接受更大revision，保留摘要、反馈及来源草稿；行意见所指文件版本变化时需人工核对新差异后迁移为文件意见。已通过/待再执行任务停止同步，退回保留轮次、指纹、意见和原基线，再执行后新增变化需重新审批。

## 边界情况

并发修改与陈旧版本必须可见拒绝；不能把机器静态摘要视为行为验收。保留既有美术交互、已有Unity改动及审批存档。失败不补造成功。

.meta永久排除显示与审批，不提供开关；底层基线仍保存其内容以保护GUID事实。任务开始前改动不认领，审批不回滚、不提交Git、不关闭计划。文件来源与结论存入工程本地持久状态，完全退出后仍恢复；自动刷新不能把未保存意见悄悄移到新版本。

## 验收条件

通过对应计划的机器检查与独立Agent审查，用户操作确认后才能关闭。禁止截图验收。

## 需求演进

### 2026-10-04 · 首次建立

根据用户十项功能优化要求拆分建立；不迁移旧文档结论作为本轮成功证据。

### 2026-10-05 · 审批以具体操作说明为正文

用户明确不接受YAML/二进制等不可读资源展示，也不接受代码只有行数简介。改为版本绑定的逐文件操作说明，保留代码diff，删除资源原始差异入口与“提交/更新审批差异”。差异后台同步，保存按钮只保存人工任务摘要。用户确认由本人导入的指定资源应按精确路径和冻结版本排除；不能据文件扩展名把同类资源统一猜为人工或Agent修改。

### 2026-10-05 · 说明生成可观测与人工动画来源

用户反馈说明按钮只显示Codex执行，不知道进度，并要求低档模型以及审批页手动模型/档位选择。独立说明配置和真实阶段回执成为必需功能。人工导入资源只按用户确认的具体文件及冻结哈希排除，保留原基线、其它文件来源、意见和中断状态。Animator控制器与动画配置不能仅按目录替它们认定作者。
