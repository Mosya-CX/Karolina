# Karolina 文档目录

- `requirements/karolina`：Karolina 功能目标与边界。
- `plans/karolina`：实施计划、测试设计、进度和验收记录。
- `plans/evidence`：计划执行证据。
- `rules/execution`：Karolina 工程规则。
- `rules/facts`：已核对的 Karolina 架构事实。
- `catalog.json`：需求、计划、事实与当前执行计划的机器索引。

文档正文使用中文；文件名与 JSON 元数据键使用英文。每份需求案或计划案的编号、状态、标签和关系保存在相邻 `.meta.json` 中。计划关闭后默认不重启；需求变动记录在需求正文中。
