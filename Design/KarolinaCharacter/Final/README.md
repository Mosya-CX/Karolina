## 角色要点

- Karolina 外冷内热；手机上的 Agent 表情以基础几何图形表达她外显克制下的真实情绪。
- 手机屏幕不显示“小K”名称。表情仅使用圆形眼睛、短线眉毛和简单弧线或几何嘴形。
- 白袜腿为单层纯白中筒袜；大腿环位于裸露的大腿上，与袜口之间留有皮肤间隔。
- 3 视图与零件图为独立图片，便于逐件替换和继续细化。
